# EECS 4314 Group Project

This is a minimal static website for Group F.

## Files

- `index.html` — main page
- `styles.css` — styling
- `script.js` — small entrance animation
- `files/Project-Presentation-1.pdf` — Project Presentation 1
- `files/Project-Report-1.pdf` — Project Report 1

## Preview locally

Open the folder in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000
